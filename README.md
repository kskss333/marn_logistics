# МАРН — корпоративный сайт

Статический адаптивный сайт на HTML, CSS и JavaScript. Сборщик и установка npm-зависимостей не требуются.

## Структура

- `index.html` — главная на русском
- `logistics.html` — логистика и грузоперевозки
- `terminal.html` — контейнерный терминал
- `containers.html` — контейнерные операции
- `modular.html` — модульное строительство
- `contacts.html` — контакты
- `en/` — полноценные английские версии всех шести страниц
- `assets/style.css` — стили и адаптивная сетка
- `assets/app.js` — мобильное меню, поведение шапки, анимации и интерактивный интерактивный 3D-глобус
- `assets/images/` — локальные изображения WebP
- `assets/favicon.svg` — favicon
- `sitemap.xml`, `robots.txt` — файлы для поисковых систем

## Запуск локально

Требуется Python 3. В каталоге сайта выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Английская версия находится в `/en/`.

## Публикация

1. Загрузите всё содержимое каталога сайта в корневую папку сайта на хостинге.
2. Сохраните структуру `assets/` и `en/` без изменений.
3. Убедитесь, что сайт работает по HTTPS.
4. Если основной домен или пути отличаются от `https://marn-group.com/`, обновите canonical, hreflang и адреса в `sitemap.xml` и `robots.txt`.
5. После публикации проверьте sitemap и обе языковые версии в инструментах веб-мастера.

- Перед реальным запуском требуется финальная проверка в целевых браузерах, Lighthouse и проверка доменных настроек на хостинге.
